# s001 资产负债表 · 智能问数答题图谱 —— 需求评审与入 SAG 方案

> 评审日期：2026-08-13
> 评审对象：在 SAG 中构建「智能问数答题图谱」，基于 s001（资产负债表）回答用户的指标口径问题（不写 SQL、不取数，只答口径与公式）

---

## 一、需求评审

### 1.1 需求本质

用户想构建的不是"写 SQL 取数的系统"，而是**口径解释器（答题图谱）**：

| 维度 | 说明 |
|---|---|
| 输入 | 用户自然语言问数（如"存货对比年初增减率怎么算"） |
| 输出 | **文本回答**：涉及哪些指标、这些值怎么算、计算公式 |
| 数据来源 | s001 资产负债表科目字典（60+ 科目、行号、特殊标记） |
| 明确不做 | 不生成 SQL、不返回具体数值（SAG 知识库不含数值数据） |

**核心边界（必须写进文档）**：Agent 只能回答"怎么算"，不能回答"是多少"。用户问具体数值时，应回答口径 + 取数指引（如"请提供期末数或查询报表"）。

### 1.2 功能需求拆分（用户 6 点）

| # | 功能 | 本质 | 文档承载 |
|---|---|---|---|
| 1 | 字段关联（存货=原材料+库存商品+数据资源） | 科目包含关系 | 科目关联图谱章节 |
| 2 | 对比年初：增减额、增减率 | 衍生指标公式 | 通用公式章节 |
| 3 | 累计环比：上月数、环比增减额/率 | 衍生指标公式 | 通用公式章节 |
| 4 | 累计同比：上年同期数、同比增减额/率 | 衍生指标公式 | 通用公式章节 |
| 5 | 特殊标记 *△#（合并/金融/外资专用） | 科目元数据 | 标记说明章节 |
| 6 | 资产负债率 = 负债总额÷资产总额×100% | 跨科目派生指标 | 派生指标章节 |

### 1.3 歧义点清单（⚠️ 需用户确认）

| # | 歧义 | 现状 | 建议口径 |
|---|---|---|---|
| A | **"年初数"定义** | 未明确 | = 上年 12 月期末数（即本年 1 月期初数） |
| B | **"累计值"概念** | 资产负债表是**时点值**，无"累计发生额" | 文档显式声明：问某月情况时"累计值=期末数=该月月末余额"，避免与利润表逻辑混淆 |
| C | **"上年同期数"两处不一致** | ①科目：去年同月期末数；②资产负债率："上年同期为期初数" | 文档分别定义：科目同比用"去年同月期末数"；资产负债率比率用"年初数" |
| D | **"本月数"语义** | 期末数-上月期末数 | 注明：约等于本月变动额（含发生额与重分类影响） |
| E | **合计行是否覆盖** | 用户未提，但问数高频 | 建议覆盖：流动资产合计(20)、非流动资产合计(48)、资产总计(49)、负债合计(89)、负债和所有者权益合计(105) |
| F | **科目范围** | 12 个启用科目 vs 全表 60+ | 建议全表收录（字典已有全部科目与行号），12 个科目标注为"已验证可取数" |
| G | **期末数时点** | 报告期月末 | 建议声明：期末数=报告期**月末**时点余额 |

### 1.4 需求边界确认

- 输入：中文自然语言问数
- 输出：文本（公式 + 科目 + 口径说明 + 取数指引）
- 不含：SQL、具体数值、好/坏判断（负债增减方向性由用户自行解读）

## 二、MD 文档设计（如何写好）

### 2.1 结构设计（检索友好，7 层）

```
# s001 资产负债表 · 智能问数答题图谱
> 用途 + 使用边界（只答口径与公式，不取数）

## 1. 报表与口径总览
   表说明（资产负债表=时点值）、口径定义表
   ★ 关键声明：问某月时"累计值=期末数"；"本月数=期末数-上月期末数"
## 2. 通用计算公式（所有科目适用）
   2.1 对比年初（增减额/增减率）
   2.2 累计环比（上月数/环比增减额/环比增减率）
   2.3 累计同比（上年同期数/同比增减额/同比增减率）
   2.4 本月数
   → 每个公式附【示例提问+示例回答】
## 3. 科目关联图谱（字段关系）
   3.1 存货 = 原材料 + 库存商品(产成品) + 数据资源
   3.2 流动资产合计 = 货币资金+应收票据+应收账款+预付款项+...+存货+其他流动资产
   3.3 资产总计 = 流动资产合计 + 非流动资产合计
   3.4 负债和所有者权益合计 = 负债合计 + 所有者权益合计
   → 每条关系附【示例提问】
## 4. 科目清单（全表，行号 + 标记）
   | 行次 | 科目 | 科目类型 | 特殊标记 | 备注 |
## 5. 特殊标记说明
   * = 合并会计报表专用 / △ = 金融类企业专用 / # = 外商投资企业专用
## 6. 派生指标
   资产负债率 = 负债总额 ÷ 资产总额 × 100%（上年同期为期初数）
   → 可扩展：流动比率、速动比率等
## 7. 问答示例集（few-shot，Agent 直接学习）
   Q/A 若干，覆盖：对比年初、环比、同比、本月数、关联、标记、资产负债率
```

### 2.2 设计要点（针对 SAG 检索特性）

| 要点 | 原因 |
|---|---|
| **通用公式独立成章（第 2 章）** | 任何科目问数都会命中公式，Agent 组装"科目+公式" |
| **科目清单与公式分离** | 问题命中科目行 + 命中公式章 = 两份证据，答案更完整 |
| **每节附【示例提问】** | 提高检索相关性 + 少样本引导 Agent 回答格式 |
| **边界声明放文档开头** | 防止 Agent 回答具体数值或混淆累计逻辑 |
| **公式用统一符号**（期末数 E / 年初数 B / 上月数 M / 上年同期 Y） | 减少模型对"增减额"等词的歧义解析 |
| **行号标注** | 回答时能指出"科目位于第 X 行" |

### 2.3 公式统一符号

| 符号 | 含义 |
|---|---|
| E（期末数） | 报告期月末余额 |
| B（年初数） | 上年 12 月期末数 |
| M（上月数） | 上月末余额 |
| Y（上年同期数） | 去年同月末余额（科目）；年初数（资产负债率） |

- 对比年初：增减额 = E − B；增减率 = (E − B) ÷ B × 100%
- 累计环比：环比增减额 = E − M；环比增减率 = (E − M) ÷ M × 100%
- 本月数 = E − M
- 累计同比：同比增减额 = E − Y；同比增减率 = (E − Y) ÷ Y × 100%
- 资产负债率 = 负债总额 ÷ 资产总额 × 100%

## 三、入 SAG 方案评审

### 3.1 可行性

| 项 | 结论 |
|---|---|
| 文件格式 | ✅ SAG 支持 .md 上传（`allowed_upload_exts` 含 .md/.markdown） |
| 检索链路 | ✅ 已打通（embedding 8008 + Agent 检索问答正常） |
| 当前生成模型 | ✅ qwen3.6-27b（43023 代理），刚验证 Agent 问答可用 |
| 多信源 | ✅ 已有多信源运行（燃料报告/故宫/解说稿），可新增"答题图谱"信源 |

### 3.2 入 SAG 步骤

1. **编写 MD 文档**（按第二章结构）
2. **上传为知识源**：`POST /api/v1/documents`（multipart，`use_ocr=false`，MD 走标准解析）
3. **等解析完成**：轮询 document 状态至 `ready`（检查 chunks 数）
4. **验证问答**：跑 3.4 验证用例，确认回答带公式、无数值幻觉

### 3.3 风险与对策

| 风险 | 对策 |
|---|---|
| Agent 回答具体数值（知识库无数据） | 文档开头边界声明 + 示例中显式"不取数"表达 |
| 科目与公式跨 chunk 组装失败 | 通用公式章独立 + 章节标题精确（"计算公式""科目关联"），必要时科目行内联关键公式 |
| qwen3.6-27b 多轮退化（此前出现空输出） | 文档问答单轮可完成；如遇多轮检索循环，可切 deepseek-v4-flash |
| "累计值=期末数"声明被忽略 | 声明放文档最前 + 第 7 章示例强化 |

### 3.4 验证用例（入 SAG 后必测）

1. "存货对比年初的增减额、增减率怎么算？" → 期望：存货=原材料+库存商品+数据资源；增减额=E−B；增减率=(E−B)/B
2. "问 2026 年 5 月存货的本月数怎么算？" → 期望：本月数 = 5 月末期末数 − 4 月末期末数
3. "资产负债率怎么算？" → 期望：负债总额÷资产总额×100%，上年同期=年初数
4. "哪些科目带 * 号？" → 期望：说明 * 为合并报表专用并列举
5. "资产总计和流动资产合计什么关系？" → 期望：资产总计=流动资产合计+非流动资产合计
